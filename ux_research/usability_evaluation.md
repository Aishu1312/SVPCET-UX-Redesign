# Usability Evaluation

## SVPCET Website Redesign - UDSA Teacher Assessment-01

### Methodology
This usability evaluation was conducted using Nielsen's 10 Heuristics for User Interface Design. The goal was to identify pain points in the existing SVPCET digital experience.

### Findings

1. **UX-01: Overlapping modals/popups (Severity: High)**
   - *Problem*: Multiple modals appear simultaneously, blocking content.
   - *Principle*: Visibility of System Status

2. **UX-02: Competing admission buttons (Severity: High)**
   - *Problem*: Confusing CTA hierarchy for admissions.
   - *Principle*: Aesthetic and Minimalist Design

3. **UX-03: Navigation hidden behind Menu (Severity: High)**
   - *Problem*: Desktop users must click a hamburger menu for primary links.
   - *Principle*: Recognition rather than Recall

4. **UX-04: Cluttered hero section (Severity: Medium)**
   - *Problem*: Overloaded hero section with text and competing visuals.
   - *Principle*: Aesthetic and Minimalist Design

5. **UX-05: Poor programme scannability (Severity: Medium)**
   - *Problem*: Academic programs listed densely.
   - *Principle*: Consistency and Standards

6. **UX-06: Weak notices (Severity: Medium)**
   - *Problem*: Important notices lost in a small marquee.
   - *Principle*: Flexibility and Efficiency of Use

7. **UX-07: No prominent search (Severity: High)**
   - *Problem*: Users cannot easily search for information.
   - *Principle*: User Control and Freedom

8. **UX-08: Contrast problems (Severity: Medium)**
   - *Problem*: Poor contrast against background images.
   - *Principle*: Accessibility

9. **UX-09: Poor mobile experience (Severity: Low)**
   - *Problem*: Elements break on smaller screens.
   - *Principle*: Flexibility and Efficiency of Use

10. **UX-10: Ungrouped footer (Severity: Low)**
    - *Problem*: Footer links are unorganized.
    - *Principle*: Consistency and Standards
