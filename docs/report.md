# UDSA Teacher Assessment-01 Report

## Usability Evaluation & Prototype Redesign of SVPCET Website

**Project Focus:** Redesigning the St. Vincent Pallotti College of Engineering and Technology website to solve key usability issues identified through UX research.

**Methodology:**
The project follows a standard HCI approach:
1. Usability Evaluation (Nielsen's Heuristics)
2. Problem Identification
3. Proposed Solutions
4. High-Fidelity Prototyping
5. Implementation

Please refer to the `ux_research/usability_evaluation.md` and `prototype/design_system.md` for detailed breakdowns. The interactive `9_UX_Evaluation.py` page in the application provides a live dashboard of these findings.
