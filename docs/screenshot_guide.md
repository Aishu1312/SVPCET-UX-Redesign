# Screenshot Guide for Submission

For the final UDSA Teacher Assessment-01 submission, ensure you capture screenshots of the following interactive elements:

1. **Home Page**: Show the clear visual hierarchy of the Hero section and Quick Access cards.
2. **Admissions Page**: Demonstrate the high-contrast CTA and structured eligibility information.
3. **Academics Search**: Take a screenshot of the search filter functioning with "Computer Science".
4. **Notices Page**: Capture the category filtering functionality.
5. **UX Evaluation Page**: Capture the interactive dashboard showing the 10 usability issues.
6. **Before/After Case Study**: Take a screenshot highlighting the design decisions and user benefits.
7. **Mobile View**: Use browser developer tools to capture the responsive layout on a mobile screen size.
