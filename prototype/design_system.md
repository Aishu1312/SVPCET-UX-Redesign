# SVPCET Design System

## Overview
This design system ensures a premium, consistent, and accessible interface for the SVPCET redesign prototype.

## Typography
- **Headings**: `Outfit` (sans-serif, bold, geometric)
- **Body Text**: `Inter` (sans-serif, highly legible)

## Color Palette

### Brand Colors
- **Primary**: Deep Blue `#0a3d62`
- **Primary Light**: `#165b8f`
- **Secondary (Accent)**: Orange/Gold `#e58e26`
- **Secondary Light**: `#f6b93b`

### Surfaces & Backgrounds
- **Main Background**: `#f8f9fa`
- **Surface White**: `#ffffff`
- **Surface Off-white**: `#f1f3f5`
- **Surface Dark**: `#212529`

### Status Colors
- **Success**: `#20bf6b`
- **Warning**: `#f7b731`
- **Error**: `#eb3b5a`

## Spacing (Tokens)
- `spacing-sm`: 8px
- `spacing-md`: 16px
- `spacing-lg`: 24px
- `spacing-xl`: 32px
- `spacing-xxl`: 64px

## Border Radius
- `radius-sm`: 4px
- `radius-md`: 8px
- `radius-lg`: 12px
- `radius-xl`: 16px
